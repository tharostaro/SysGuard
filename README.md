# SysGuard 

**A Python-based Linux System Monitoring Tool.**

SysGuard is a lightweight Linux monitoring application written in Python. It provides basic system information and resource monitoring through an interactive terminal interface.

## Features

- System Information
- CPU Usage Monitoring
- RAM Usage Monitoring
- Running Processes Viewer
- Disk Usage Monitoring
- SQLite Metrics Database
- Logging System
- Metrics History

## Technologies

- Python
- psutil
- SQLite3
- Linux

## Installation

```bash
git clone https://github.com/tharostaro/SysGuard.git
cd SysGuard

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
python3 sysguard.py
```
